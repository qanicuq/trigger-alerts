# trigger-alerts

Paper trading bot that watches conditions and alerts for manual confirmation.

## How it works

You drop a trigger file into the inbox folder. The bot checks every half hour during market hours. When all conditions are true it paper-buys automatically (no confirm needed), sizing the trade with a safety formula, then tracks the paper position and sends a phone alert. If a safety rule blocks the buy, the alert says why, and you can still retry it that day with the Confirm trade workflow. If a Forensic Analysis stock buy is blocked because there is no cash and its upside (target ÷ price − 1) is lower than every stock already held, the buy is held and a fresh Forensic Analysis runs first (the daily re-run task). If the fresh report still comes out weaker when its conditions are met, the trigger is shelved for two weeks and then tried again; an AVOID report cancels it. Stops and time exits close automatically. After each earnings report a fresh Forensic Analysis runs on every stock held; it moves the target and stop to the fresh numbers (the stop is never lowered), or sells (trims 10% of the profit for a franchise) if value is no longer above the price, and an AVOID verdict sells. A Forensic Analysis stock that reaches its target is held and you get an alert to run a fresh analysis; the fresh analysis then keeps it, trims 10% of the profit (franchise), or sells it. Option trades (single options, spreads and other option positions) use their own separate $5,000 paper account (added 2026-11-16), so a fully invested stock account never blocks them; a single option or spread is always 1 contract when the option cash covers it. Stocks never risk more than a small fraction of the $10,000 stock account and pauses new buys if down 10% from its high. Reports arrive three times a day. Everything stays paper — no real money moves.

## Watchdog

A separate GitHub schedule (not cron-job.org) checks that the half-hour checks really ran, on weekdays that are not NYSE holidays. It sends a phone alert if a check is late, once before the open (did yesterday's last check run?) and once after the close (a quiet "all good" if the day's last check ran). See `watchdog.py` and `.github/workflows/watchdog.yml`.

## No cash, swaps and chart-based triggers (2026-11-20)

A stock buy will not take leftover dust. The bot first figures a normal buy (the safety-formula size, capped by the position limit). If the cash on hand is less than a third of what that normal buy costs, it refuses with "no cash" and buys nothing. If cash covers at least a third but not the whole normal buy, it buys as many shares as the cash allows, rounded down to 4 decimals.

When that refusal is a forensic stock buy, the bot compares the new stock with the weakest stock already held (the one with the lowest upside, target ÷ price − 1). It also compares upside per $1 of downside, (target − price) ÷ (price − stop), which is 0 when a stop is missing. If the new stock is higher on both, and this check has not already been done, nothing is sold yet. The bot asks for a fresh Forensic Analysis of that weakest holding. The daily re-run task picks it up (every day at about 12:47 PM). The holding is sold only if that report says sell. While the check is open the new trigger stays active and is not bought. The wait ends when the holding is gone, or when the fresh analysis has come back and been applied. If the holding is kept, the new buy is shelved for 14 days. If the holding is sold, the bot tries the new buy again with the freed cash; if there is still not enough cash, it can check the next weakest holding the same way. If the new stock is not clearly better on both measures, the old path stays: a fresh analysis of the new stock first, then a 14-day shelf if it is still not clearly better.

A forensic buy whose recommendation says "chart-based entry" is not paper-bought when its conditions are met. The bot sends one alert that day and leaves the trigger active. The report is not calling it a value bargain, so there is no margin of safety. A normal value trigger is still bought automatically.
